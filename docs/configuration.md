# Configuration, Toolchains & Accessibility (`docs/configuration.md`)

This repository runs 100% offline with **no required API keys, environment variables, or external services**.

## Declarative Configuration Files

| File | Purpose |
|---|---|
| `VERSION` | Single source of truth for semantic version (`2.3.1`). |
| `pyproject.toml` & `requirements.txt` | Python package manifest and pinned/bounded dependency specification. |
| `lean/lean-toolchain` & `lean/lakefile.toml` | Pure Lean 4.35.0 toolchain configuration (zero Mathlib dependencies). |
| `schema/problem.schema.json` & `schema/atlas.schema.json` | JSON Schema Draft 2020-12 contracts for all 1,900 records × 48 fields. |
| `repo.yaml` & `repo-standard.schema.json` | Build Standard v1.2.0 machine-readable manifest and validator schema. |
| `.zenodo.json`, `croissant.json`, `ro-crate-metadata.json` | FAIR scholarly metadata manifests regenerated by `scripts/generate_fair_metadata.py`. |
| `.gitleaks.toml` | Secret-scanner allowlist for audit regex scripts. |

## Optional Environment Variables

- `ZENODO_TOKEN` *(optional, only when manually executing `scripts/publish_zenodo.py --publish`; `--dry-run` requires no credentials)*.

## Accessibility & Internationalization (Build Standard `A38`)

- The static interactive web atlas (`outputs/MegaAtlas_Interactive_Dashboard_V2.html`, served on GitHub Pages) uses semantic HTML5 landmarks, UTF-8 encoding, keyboard-navigable filter controls and search inputs, high-contrast color palettes, and 15 charts exported in both scalable vector SVG and 220 DPI PNG.
- Primary language is English (`lang="en"`), with Unicode mathematical symbols and UTF-8 author diacritics preserved across CSV, TSV, JSON, JSONL, SQLite, HTML, and PDF exports.
