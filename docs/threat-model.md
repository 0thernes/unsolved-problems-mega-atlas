# Threat Model & Security Analysis (Build Standard B36)

This repository is an offline-first scientific dataset, Lean 4.35.0 software-model proof suite, static HTML/JS web dashboard, SQLite FTS5 RAG CLI, and local stdio MCP JSON-RPC 2.0 server. It runs **no public web backend, handles zero user authentication or PII, and makes zero runtime outbound network calls**.

## 1. STRIDE Analysis Across Trust Boundaries

| Surface | Threat (STRIDE) | Concrete Risk | Mitigation Implemented |
|---|---|---|---|
| **MCP Stdio Server (`mcp_server/server.py`)** | Tampering / Injection / DoS | Malformed/non-object JSON-RPC, negative/truncated/multi-GB `Content-Length` or unbounded NDJSON lines, SQL injection or type confusion via `query`, `pillar`, `superdomain`, `flag`, `substrate`, or `metric` arguments | Strict parameterized SQLite `?` bindings; allowlist validation on `metric` enum (`allowed = {...}`); strict `1 MiB` (`1..1,048,576`) frame cap on BOTH `Content-Length` and NDJSON lines (with truncated-frame rejection & drain); non-object JSON `-32600` guard; `4,096`-char query cap; strict `_parse_opt_str` filter validation; clamped integer `limit`/`top`/`hops` rejecting JSON booleans; negative boundary tests in `tests/test_properties_and_differential.py`. |
| **SQLite FTS5 Query (`rag/query.py`)** | DoS / Filter Bypass / FTS5 Syntax Injection | Special characters (`"`, `*`, `NEAR/`, unbalanced parens) crashing FTS5 `MATCH`, exact-ID queries bypassing `pillar`/`superdomain`/`flag` filters, or stale cached SQLite serving old versions | `tokenize_query()` strips non-alphanumeric chars via `re.findall(r"[A-Za-z0-9_]+", raw)` and wraps every token in safe double quotes before `MATCH ?`; exact-ID shortcut enforces all active WHERE filters; `O(1)` stat-cached `_db_is_fresh()` auto-rebuilds stale caches on upgrades. |
| **Interactive Web Atlas & Proof Blueprint (`outputs/MegaAtlas_Interactive_Dashboard_V2.html`, `blueprint/index.html`)** | Cross-Site Scripting (XSS) / External Resource Exfiltration | Malicious HTML/script payloads inside problem fields or modal neighbor links, `</script>` breakout, or untrusted CDN loads | Strict zero-CDN `Content-Security-Policy` (`default-src 'none'; connect-src 'self'; img-src 'self' data:; style-src 'unsafe-inline'; script-src 'unsafe-inline'; base-uri 'none'; form-action 'none';` — same-origin only for `./daily_registries.json`) + `Referrer-Policy: no-referrer`; every dynamic text interpolation (including `${esc(rid)}`) passes through `esc()` HTML entity escaping in JS and `html.escape()` in Python; embedded JSON escapes `</` as `<\/`. Static read-only pages with zero user-submitted backend persistence. |
| **Lean 4.35.0 Formal Proofs (`lean/`)** | Spoofing / Proof Forgery | Hidden `sorry`, `admit`, `native_decide`, `unsafe`, `implemented_by`, `@[extern`, `opaque`, `Lean.ofReduceBool`, custom `axiom` (including modifier-prefixed `private axiom`), or statement drift between paper and proof | Hardened H46 scanner in `scripts/audit_atlas.py` & `tests/test_mega_atlas.py`; exact 103-line `results/lean_axioms.txt` parity check & verbatim README drift checker (`scripts/check_readme_axioms.py`); live negative kernel rejection test; `6` kernel checks across `5` distinct implementations + `leanchecker --fresh` via `scripts/verify_lean_six_kernels.sh`. |
| **Supply Chain / Release Artifacts & Daily Sync** | Tampering / Repudiation | Corrupted PDF, arXiv tarball, Track B probe results, or dataset files after build, or daily automation corrupting frozen seals | `78`-file `CHECKSUMS.sha256` + structurally verified dual timestamps (DigiCert RFC 3161 ASN.1 `CHECKSUMS.sha256.tsr` + full OTS v1 binary tree `CHECKSUMS.sha256.ots`) + `13`-file `data/MANIFEST.sha256` verified in CI; volatile daily registry telemetry (`results/daily_registries.json`, `results/lefttosolve_programs.json`, `results/daily_registry_history.jsonl`, `docs/DAILY_REGISTRY_TRACKER.md`) isolated strictly outside frozen checksums and never auto-retires cataloged problems; deterministic archives (`mtime=0`); GitHub `actions/attest-build-provenance@v2` SLSA provenance attestations on `main` pushes. |
| **Optional Zenodo Token (`scripts/publish_zenodo.py`)** | Information Disclosure | Accidental secret commit to git | `.env` gitignored; `.env.example` contains empty placeholders only; CI runs regex secret-leak scan (`ghp_`, `sk-`, `AKIA`, private key headers). |

## 2. OWASP LLM / Agentic Consumption Risks (MCP & `llms.txt`)

- **Prompt Injection via Corpus Text:** Because the corpus is authored and audited statically in `src/v2_data/`, all 2,000 records are deterministic and git-versioned. MCP tool responses return structured JSON strictly tagged with `verification_flag`, `ai_disclosure`, and `conflict_of_interest_disclosure` so consuming agents cannot conflate editorial estimates or unverified AI claims with peer-reviewed facts.
- **Reward Hacking in AutoResearch:** Immutable `autoresearch/evaluate.py` + Lean-verified `failed_gates_always_discard` theorem prevent an autonomous agent from inflating `AQS` while breaking schema, biconnectivity, or Lean zero-sorry gates.
