# Runnable Examples (`examples/`)

Runnable scripts demonstrating the offline Hybrid BM25+PageRank RAG engine and pairwise problem comparator without requiring any external API keys.

## Run

```bash
python3 examples/query_demo.py
```

See also CLI flags in `rag/query.py --help` and MCP server instructions in [mcp_server/README.md](../mcp_server/README.md).
