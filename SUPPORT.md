# Support & Getting Help

Thank you for exploring the **Unsolved Problems Mega-Atlas**.

## Where to Ask Questions or Report Findings

- **Bugs, data corrections, or broken links:** Open a GitHub Issue using the [Bug / Defect Report](https://github.com/0thernes/unsolved-problems-mega-atlas/issues/new?template=bug.yml) template.
- **Open-problem status updates or falsification evidence:** Use the [Status Update or Falsification](https://github.com/0thernes/unsolved-problems-mega-atlas/issues/new?template=status-update-or-falsification.yml) template with primary citations/DOIs.
- **Proposing a new open problem:** Use the [Propose Open Problem](https://github.com/0thernes/unsolved-problems-mega-atlas/issues/new?template=propose-problem.yml) template.
- **Academic & formal-verification review:** Use the [Academic / Formal Verification Review](https://github.com/0thernes/unsolved-problems-mega-atlas/issues/new?template=academic-review.yml) template.
- **General questions:** Open a [Question](https://github.com/0thernes/unsolved-problems-mega-atlas/issues/new?template=question.yml) issue or email `0_0@0thernes.art`.
- **Security vulnerabilities:** Follow [`SECURITY.md`](SECURITY.md) — do not file public issues for sensitive reports.
