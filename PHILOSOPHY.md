# Research Philosophy & Epistemic Design Principles

The **Unsolved Problems Mega-Atlas (`v2.10.0`)** is built around five non-negotiable engineering and scholarly principles:

1. **Radical Epistemic Honesty Over Hype:** Never conflate an unrefereed AI proof dump with a community-retired theorem; never conflate machine-checked software-model invariants (`103` audited Lean 4.35.0 theorems of `117` declarations in `lean/`) with proofs of the `2,000` open problems themselves (`0 / 2,000` solved); never conflate solo editorial scores with peer-reviewed ground truth.
2. **Falsifiability by Construction:** Every quantitative score, taxonomic placement, cross-reference edge, and ranking in `RANKING.md` is generated deterministically from human-readable source files (`src/v2_data/`). Disagree with a rating or link? Edit the record or run `just rubric-diff` (`scripts/rubric_override_diff.py`) and argue directly from the diff.
3. **Layered Defense-in-Depth Verification:** Combine Lean 4.35.0 software-model kernel verification (`6` kernel checks across `5` distinct implementations on the `9` Palomar targets: `lean`/`leanchecker-paranoid`, `lean4lean`, `nanoda_bin`, `con-leche`, `con-ron`), an independent 50-digit `Decimal`/`Fraction` reference oracle, 1,000-example Hypothesis property testing, 100% (`12/12`) semantic mutation-kill auditing, JSON Schema Draft 2020-12 validation, and an immutable AutoResearch evaluator (`autoresearch/evaluate.py`).
4. **Offline-First, Zero-Lock-In Preservation:** Zero API keys, zero cloud vendor lock-in, zero binary blobs `>= 5 MB` in git history, deterministic archives (`mtime=0`), FAIR JSON-LD metadata (`croissant.json`, `ro-crate-metadata.json`, `.zenodo.json`), structurally verified DigiCert `.tsr` + Bitcoin OTS v1 `.ots` timestamps, clean-room reproducible AMS-LaTeX source (`dist/arxiv_submission.tar.gz`), and daily advisory registry syncs isolated strictly outside frozen cryptographic seals.
5. **Cross-Disciplinary Connectomics Without Reductionism:** Wire formal mathematics, quantum/spacetime physics, materials, biology/mind, AI/computing hardware, engineering/climate, and philosophy/humanities into a single biconnected graph (`6,108` edges, `0` articulation points, audited in Python/NetworkX) while preserving each domain's distinct epistemic verification standard (`Formal-Deductive` through `Normative-Philosophical`).
